# Environment variables

Set these in DigitalOcean App Platform (Settings → App-level environment variables). Mark secrets as **Encrypted**.

**Local files (monorepo):**

| File | Read by | Holds |
|---|---|---|
| `apps/web/.env.local` | `npm run dev` (Next.js reads env from its own folder) | App variables below; copy the app part of `.env.example` |
| `.env` (repo root) | `docker compose` (via `--env-file .env` in the `stack:*` scripts) | Stack secrets (DB roles, Redis, Garage, S3 keys); created by `npm run stack:env`, never committed. List: `docs/INFRA.md` → Secrets |

Both files are git-ignored. `docker compose` refuses to start if a secret in `.env` is missing. The dev stack sets the web app's variables itself in `infra/compose.dev.yml`, with no secrets inline.

| Variable | Required | Example / values | Purpose |
|---|---|---|---|

| `DATABASE_CA_CERT` | yes on DO | `${db.CA_CERT}` | Managed Postgres CA certificate (PEM text) |
| `SESSION_SECRET` | secret | 32+ random characters | Signs session cookies (web and api share it; generated by `npm run stack:env`) |
| `OTP_PEPPER` | secret | 32+ random characters | Hashes email sign-in codes (web and api; generated by `npm run stack:env`) |
| `MAIL_DRIVER` | yes | `resend` · `ses` · `console` | Email provider |
| `MAIL_FROM` | yes | `PnL Lens <no-reply@pnllens.com>` | Sender |

| `PAYMENTS_MODE` | no | `off` · `link` · `razorpay` | See `docs/PAYMENTS_RAZORPAY.md` |
| `PAYMENT_LINK_<PLAN>_<INR\|USD>` | link mode | `https://rzp.io/...` | Pasted Razorpay links (8 total) |

| `CRON_SECRET` | optional | | Only if purge is triggered over HTTP |

| `REDIS_URL` | api, worker | from compose | BullMQ queue and the rate-limit store |
| `WORKER_CONCURRENCY` | worker | `2` | Analysis jobs at once per worker container |
| `API_INTERNAL_URL` | web | `http://api:4000` | Where the website's server side reaches the API (private network); the web app has no DB or session secrets since Phase 6 |
| `ENGINE_TIMEOUT_MS` / `ENGINE_MEMORY_MB` | worker | `60000` / `512` | Limits for the engine child process (a file past them fails as `timeout` / `too_complex`) |

| `DATABASE_URL`, `REDIS_URL`, `S3_ENDPOINT`, `S3_REGION`, `S3_BUCKET`, `S3_ACCESS_KEY_ID`, `S3_SECRET_ACCESS_KEY` | api / worker containers | built in `compose.dev.yml` from the values above | Per-service connection settings |
